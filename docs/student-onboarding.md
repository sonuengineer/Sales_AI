# Student Onboarding Guide

Welcome to the **Sales Intelligence, CRM & AI Automation Mastery** platform. This guide walks you from first sign-in to your certificate, using only the fictional NexaFlow demo data built into the platform.

## 1. Sign in

Use the student demo account:

- Email: `student@nexaflow.demo`
- Password: `demo123`

These credentials are for local development only. Never enter real personal or customer data anywhere in this training environment.

## 2. Complete the course

Open **My Learning** and work through the 10 modules in order. Each module has a short lesson. Mark lessons complete as you finish them — your course progress updates immediately.

## 3. Practise with the tools

- **CRM Lab** — explore Companies, Leads and Opportunities. Open a lead, review its score breakdown, move it through stages and log activities. Everything you do is on fictional records.
- **Workflow Lab** — see how lead scoring and assignment rules work, run the simulator, and experiment safely in the sandbox (your experiments never touch the shared data).
- **Analytics** — read the KPI cards, funnel, TAT and stale-lead reports. Use the period filters and CSV export for spreadsheet exercises.
- **AI Practice Lab** — run the six simulated AI templates and review AI follow-up drafts. Outputs are simulated, so verify anything before acting on it. No message is ever sent automatically.

## 4. Prove your learning

- Take the **quiz** for each module. Quizzes are auto-scored with review feedback.
- Submit each **assignment** as text or a link. An instructor reviews, scores and comments; if work is returned, revise and resubmit.
- Build the **Capstone**: ten deliverables that combine everything. Submit each one, request final review, and fix anything returned until the instructor approves it.

## 5. Earn your certificate

A certificate is issued automatically when you meet all three criteria:

| Criterion | Target |
| --- | --- |
| Course completion | 80% of lessons |
| Assessment score | 70% average (quizzes + graded assignments) |
| Capstone | Approved |

Open **Certificates** to see your live progress. When all three are met, click **Issue my certificate**, then open the printable view — it includes a unique verification ID anyone can check.

## Need help?

- Check the in-app help panels on each page for plain-language explanations.
- All data is fictional: practice freely, you can always run `npm run db:seed` to reset.
